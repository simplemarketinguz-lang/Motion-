# Simple Agent: напоминания об обещаниях

Бот читает твои чаты в Telegram, находит, где **ты** что-то пообещал («скину завтра», «выложу вечером», «хоп, сделаю»), и напоминает выполнить. Напоминания приходят в **«Избранное»** (Saved Messages).

## Как это работает

1. Ты пишешь сообщение в любом чате.
2. Бот ждёт 90 секунд, пока разговор утихнет, и отправляет последние 25 сообщений этого чата в Claude.
3. Claude находит обещания, вычисляет срок («завтра вечером» → завтра в 19:00) и формулирует задачу: «Отправить Азизу КП по SMM».
4. В «Избранное» приходит карточка: 📌 *Зафиксировал обещание*.
5. За час до срока бот присылает 🔔. В момент срока: ⏰. Если обещание не закрыто, бот повторяет напоминание каждые 4 часа.
6. Каждое утро в 9:00 приходит дайджест: что просрочено, что сегодня, что без срока.
7. Если позже ты пишешь «отправил» / «вот файл», бот **сам закрывает** обещание.

Понимает русский, узбекский (латиница и кириллица) и английский.

## Команды (пишутся в «Избранное»)

| Команда | Что делает |
|---|---|
| `/list` | все открытые обещания |
| `/done 12` | отметить выполненным |
| `/cancel 12` | это не обещание или уже неактуально |
| `/reopen 12` | вернуть закрытое обещание |
| `/snooze 12 2h` | отложить (`30m`, `2h`, `1d`, `завтра`) |
| `/scan 3` | найти обещания за последние N дней (полезно при первом запуске) |
| `/help` | справка |

## Запуск

Нужен Python 3.10+ и компьютер или сервер, который работает постоянно (подойдёт VPS за $4–5 в месяц).

```bash
cd simple-agent/bot
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # и заполни значения
python main.py
```

Что положить в `.env`:
- `TG_API_ID`, `TG_API_HASH`: на https://my.telegram.org → *API development tools* → создать приложение.
- `ANTHROPIC_API_KEY`: на https://console.anthropic.com → *API Keys*.

При первом запуске бот спросит номер телефона и код из Telegram. Это вход в **твой** аккаунт. После этого появится файл `simple_agent.session`, и больше код спрашиваться не будет.

Чтобы бот работал круглосуточно на сервере, запусти его через `systemd`, `pm2` или `screen`.

## Стоимость

По умолчанию стоит `claude-opus-5-5`, он самый точный. Один анализ чата стоит примерно $0.005–0.01. Если ты пишешь много, поменяй в `.env` на `CLAUDE_MODEL=claude-haiku-5-5`: это примерно в 40 раз дешевле, а для такой задачи качество обычно достаточное.

## Безопасность (важно)

- **Файл `simple_agent.session` = полный доступ к твоему Telegram.** Никому его не передавай и не коммить (он уже в `.gitignore`).
- Переписка отправляется в Claude API (Anthropic) для анализа. Чаты, которые не должны туда попадать, добавь в `EXCLUDE_CHATS` (через запятую, id или @username).
- Бот ничего не пишет другим людям. Он только читает и отправляет сообщения тебе в «Избранное».
- Каналы и чаты с ботами не анализируются. Группы можно отключить: `INCLUDE_GROUPS=false`.
