# Motion animation skills

Agent skills for motion design and animation, loaded automatically by Claude Code from `.claude/skills/`.

| Group | Skills | Source |
|---|---|---|
| Remotion (video in React) | `remotion-*` (best-practices, create, render, studio, multimedia, captions, markup, docs, interactivity, maps, upgrade) | [remotion-dev/skills](https://github.com/remotion-dev/skills) (official) |
| GSAP | `gsap-core`, `gsap-timeline`, `gsap-scrolltrigger`, `gsap-plugins`, `gsap-react`, `gsap-frameworks`, `gsap-utils`, `gsap-performance` | [greensock/gsap-skills](https://github.com/greensock/gsap-skills) (official, MIT) |
| Web animation libraries | `motion-framer`, `animejs`, `lottie-animations`, `react-spring-physics`, `scroll-reveal-libraries`, `animated-component-libraries`, `rive-interactive`, `locomotive-scroll`, `barba-js` | [freshtechbro/claudedesignskills](https://github.com/freshtechbro/claudedesignskills) (MIT) |
| Video motion (Remotion + GSAP/springs) | `gsap-animation`, `react-animation`, `spring-animation`, `video-producer` | [notedit/happy-skills](https://github.com/notedit/happy-skills) (MIT) |

To update, re-clone the source repo and copy the skill folder over.
